# ZSE Value Scanner patches

Versioned, non-destructive patch bundles for the ZSE Value Scanner research project.

Each patch lives under `patches/vX.Y.Z/` and includes an apply script, source/test files, notes, and checksums. Apply patches only to the exact base version stated by the patch, then run the full project test suite.

Large operational data, SQLite databases, downloaded reports, models, API keys, and research warehouse contents do not belong in this repository.
